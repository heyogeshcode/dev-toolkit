# Contributing Guidelines

Thank you for your interest in contributing to `dev-toolkit`!

## Getting Started

1. Fork or branch from `main`.
2. Make modular, well-tested contributions.
3. Follow conventional commit messages (`feat:`, `fix:`, `docs:`, `test:`).
4. Ensure all code includes appropriate documentation and type annotations.

## Code Standards

- Keep functions pure and decoupled where possible.
- Write descriptive documentation and comments.
- Avoid introducing external runtime dependencies for basic helper utilities.
